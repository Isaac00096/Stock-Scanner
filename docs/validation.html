How to read this. Every setup is tested on older data (in-sample), then on the most recent 3 years (out-of-sample), which is the number that counts. "Win rate" is how often past trades made money, with the 95% confidence range in brackets. "Baseline" is the same trade entered on random days; a setup has to beat it. Only validated setups appear on the daily dashboard. Returns are per trade, after 0.05% cost per side.

Caveats: tested only on stocks listed today (delisted losers are missing, which flatters results); trades across many stocks on the same day move together, so the t-stat is optimistic. Past results don't guarantee future ones.
